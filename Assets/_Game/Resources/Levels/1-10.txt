# **도시의 마지막 판**이라 여기서 부산 한 구역이 정복된다 (월드맵은 좀비퀸 것 그대로, §3b).
#
# 처음 판에서 `add 50` 과 `mul 3` 이 **둘 다 75** 로 떨어져서 첫 게이트가 장식이었다 (LL 과 RL 의
# 숫자가 하나까지 같았다). 그리고 두 번째 게이트는 R 쪽 지역이 82 % 를 녹여서 **고를 것이 없는
# 함정**이었다. 둘 다 `tools/sim` 이 잡았다 — 단, 두 번째는 *"이기는 경로가 둘 이상이면 갈려야
# 한다"* 로 규칙을 고친 뒤에야 걸렸다.
#
# ⚠ **곱하기의 대가는 절대값으로 치른다.** 지역은 머릿수에 비례해 깎으므로(`Sim.TickZones`)
# ×2 뒤의 지역은 그냥 배수를 줄이는 것이고, 고른 차이가 비율 안에서 사라진다. 그래서 큰 쪽
# 차선에는 **벽(시간)과 적 무리**를 둔다 — 전선 폭 위에서는 손실이 머릿수와 거의 무관하므로
# 군단이 클수록 **상대적으로** 싸게 치르고, 그게 곱하기를 고른 보람이 된다.
