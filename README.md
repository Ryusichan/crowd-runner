# crowd-runner

세로형 모바일 **군중 러너 + 자동 전투**. 자동 전진하는 군단을 좌우로 움직여 증식 게이트를 고르고,
적 방어선을 돌파해 최종 전투에서 이기면 다음 스테이지로 간다. 건설·기지·RPG 성장 요소는 없다.

- **설계안**: `docs/DESIGN.md` — 먼저 증명할 것 · 구조를 가르는 선 · 지금 정할 것 · 만드는 순서
- **기획서(GDD v1.0, 오너 2026-10-08)**: 아직 저장 안 됨 → `docs/GDD.md` 로 넣어야
  `DESIGN.md` 의 `기획서 §N` 인용이 실제 문서를 가리킨다

> **이름에 대하여**: 참고한 광고는 다른 회사의 게임이다. 가져오는 것은 **메커니즘**이고
> (게임 규칙은 저작권의 대상이 아니다), 캐릭터·UI·아이콘·맵·수치·이름은 가져오지 않는다.
> 그래서 프로젝트 이름도 장르다. 자세한 선은 `docs/DESIGN.md` §0.

## 상태

**아직 코드 없음.** 다음 한 걸음은 `DESIGN.md` §5 의 **M0** — 빈 프로젝트에 캡슐 1,000 개를
고정 스텝으로 움직여 **실기 30fps** 를 넘는지 보는 것. 아트도 게이트도 UI 도 그 뒤다.

M0 를 첫 주에 두는 이유는 하나다: 이 게임에서 **못 할 수도 있는 일이 그것 하나**이고,
못 하면 설계를 통째로 바꿔야 하기 때문이다.

## 쓸 환경

좀비퀸(`../zombie-queen-unity`)과 **코드는 공유하지 않는다** — 장르가 다르다.
**가져오는 것은 방법**이다 (`DESIGN.md` D5):

- 고정 스텝 한 틱 (`Step(dt)`), 프레임과 무관한 결정적 결과
- `Core/` 를 Unity 없이 컴파일해 돌리는 **오프라인 검사기** — 컴파일이 레이어 규칙을 강제한다
- 주행마다 **커밋 해시와 더러운 파일**을 찍는 테스트 래퍼 (숫자가 어느 코드의 것인지 남긴다)
- 빌드/배포 스크립트
